Реализованный функционал:
1. Игрок может двигаться вправо и влево; и прыгать, когда он стоит на земле*
   (Как работает проверка, что он стоит: есть переменная is_grounded, которая становится True, когда игрок находится в касании с объектом с тегом Ground и находится сверху от него,
   и False, когда он прекращает касание с объектом с тегом Ground или находится ниже)
2. Есть монетки, которые при касании игрока добавляют балл к счётчику и исчезают
3. Есть текст, показывающий количество монет
4. Есть поле финиша, при касании с которым время ставится на паузу, появляется надпись "Вы победили" и возможность сыграть ещё раз (кнопка, перезапускающая сцену)
5. Есть возможность выйти из игры нажатием на крестик или кнопкой Escape
6. По бокам есть спрятанные стенки, которые не позволяют упасть за границы экрана

* На самом деле с прыжками есть несколько багов, я часть из них исправила, но для части пока не удалось найти причину. Сейчас, во-первых, есть возможность иногда прыгать, касаясь платформы сбоку (кажется, если до этого игрок был на платформе и сполз), во-вторых, иногда получается как-то распрыгаться и улететь выше, чем надо (тоже, кажется, при касании сбоку, наверное, это связано с комбинацией ускорения ещё не закончившегося прыжка и нового).
